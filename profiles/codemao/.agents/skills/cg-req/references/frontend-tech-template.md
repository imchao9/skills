# 前端技术方案模板

用于生成前端技术方案。仅当需求涉及页面、路由、组件、前端状态、配置、第三方前端库、前端体验或前端工程改造时使用；纯后端需求不要生成本模板。

来源模板：
- 钉钉文档：`前端技术方案模版`
- 节点：`NZQYprEoWoe2DPmQtMDgwX53J1waOeDk`

## 生成规则

- 技术方案第一节必须是 `需求依据`，引用原始钉钉链接、整理后需求文档、引用需求资料、本地方案或对话确认记录。
- 必须说明 `implementation_surface=frontend` 或 `implementation_surface=fullstack`。
- 必须填写 `CheckList`、`目录`、`组件设计`、`数据管理`、`技术规范确认`、`相关文档`。
- `当前需求的流程梳理和自我理解`、`接口`、`技术优化`、`第三方库引入` 按需填写；涉及页面跳转、接口联调、性能/体验优化、第三方库时必须填写对应章节。
- 涉及公共组件、配置文件、数据管理、路由/页面时，对应章节必须写清楚变更点、影响范围和验证方式。
- 不确定的前端影响写入 `待确认事项`；如果会影响页面行为、状态流转、接口联调、权限、验收或发版范围，保持待确认，不输出完成态前端技术方案。
