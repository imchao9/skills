# 钉钉表格浏览器回填

使用本地 Chrome 回填钉钉表格时完整执行本文件。正常路径固定为两次浏览器调用：第一次只读定位与保护，第二次写入与最终验收。复用 Chrome 登录态，不检查 Cookie、Local Storage 或账号凭证。

## 调用一：只读定位与写前保护

在一次浏览器调用中依次完成：

1. 确认配置中的文档和 `Sheet1`，把焦点放入表格网格。
2. 按 `Ctrl+Home` 回到 A1，一次复制覆盖日期、人员、全部指标和所有计划截图列的首行区域，从剪贴板 TSV 解析实际表头。规范化指标关键字时转小写并移除空格、`-`、`_`；每个关键字只能匹配一列。
3. 回到日期列表头，在调用内部用 `Ctrl+↓` 循环跨越数据块，保存最后一个非空日期；下一行是目标行，不复用中间空行。
4. 一次复制目标行的全部计划写入单元格，确认均为空；非空时返回失败并禁止写入。
5. 返回工作表、表头映射、最后非空日期、目标行号、目标列和空行结论。

禁止点击或编辑名称框、使用 `Ctrl+G`、为中间落点截图，或改用“从物理底部向上定位”。

完成标准：一次只读调用返回完整写入计划，且目标行全部计划单元格为空；调用没有修改表格。

## 调用二：写入与最终验收

只在调用一成功后发起一次浏览器调用，并在其中依次完成：

1. 在内存中构造从日期列到最后一个指标列的单行 TSV，选中目标行日期单元格后一次粘贴；多行峰值保留在同一单元格。
2. 只接收已通过成品验收的图片字节，按文件签名使用正确 MIME 和 Base64 写入标签页图片剪贴板。
3. 从“服务监控情况”列开始，依次把 SLS 截图和 Grafana 截图粘贴为单元格图片。当前顺序为 J、K、L、M、N；逐张捕获失败并继续，不打开文件选择器或创建自由浮动图片。
4. 统一把目标行行高设置为 `sheet.image_row_height`，不修改列宽。
5. 等待页面显示“已保存”，返回文字、每张图片和行高的写入状态，以及一张最终表格截图。

禁止插入、删除、排序、筛选或移动列。文字成功后不逐格读回；图片成功后不逐张生成验证截图。

检查最终截图，确认仍在 `Sheet1`、目标行可见、计划图片单元格显示缩略图、页面显示“已保存”。只有明确写入失败的项目才允许再次调用重试；成功项目不得重写。

完成标准：第二次调用完成全部计划写入和唯一一次最终验收，目标行之外没有修改，失败项有明确状态。
