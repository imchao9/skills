# Core Profile

默认最小集，只放稳定自研或长期自维护 skill。

当前包含：

- `draft-internal-requirement-brief`
- `install-profile-skills`
- `workflow-packaging-audit`
- `technical-deck-qa`
- `weekly-business-report`

篮球剪辑与比赛复盘等领域能力只放在 `profiles/basketball`；`core` 保持跨项目的默认最小集。

根目录 `.agents` 指向：

```text
profiles/core/.agents
```
