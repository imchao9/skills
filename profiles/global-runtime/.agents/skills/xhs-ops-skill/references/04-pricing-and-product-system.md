## 价格带逻辑

常见结构：

- 引流带：19.9-39.9
- 主销带：59.9-199
- 利润带：299+

目标不是压低单价，而是建立“低门槛进入 + 可持续升级”。

## 三层 SKU 结构

L1 引流：

- 解决单点问题
- 交付快、理解门槛低
- 目标是转化首单

L2 主销：

- 解决流程问题
- 提供更完整的使用路径
- 目标是提高客单与复购

L3 利润：

- 解决系统问题
- 强调持续更新与陪伴服务
- 目标是形成高信任用户池

## 高定价底层

高价成立的前提是“系统价值”而非“资料数量”：

- 把交付变为系统：方法 + 模板 +执行流程。
- 提供持续更新机制：周更/月更。
- 补充服务能力：答疑、社群、案例陪跑。

## 升级路径设计

示例路径：

`低价试用 -> 场景模板包 -> 系统会员/长期计划`

每层必须写清：

- 解决什么问题
- 交付什么内容
- 与上一层差异
- 升级后新增收益
