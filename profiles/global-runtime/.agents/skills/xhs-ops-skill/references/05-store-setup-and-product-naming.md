# 05 开店与商品命名

## 目录

## 开店路径

- 冷启动阶段优先走流程更简单的开店路径。
- 先验证成交，再补复杂资质或扩店策略。

## 商品定义原则

- 拒绝大而全，优先小而垂。
- 搜索型需求优先：用户能明确搜索出来的问题。
- 一次只解决一个具体问题，降低决策成本。

## 命名结构

建议结构：

`时效词 + 场景词 + 结果词 + 承诺词`

示例：

- `2026春招｜面试决策模板｜拍下发货｜持续更新`
- `一人公司执行系统｜第二大脑行动版｜24小时发货`

## 高转化词库

可按场景组合使用：

- 时效词：`2026`、`26届`、`下半年`、`春招`、`秋招`
- 承诺词：`持续更新`、`永久更新`、`拍下发货`、`24小时发货`
- 可用性词：`可编辑`、`高清PDF`、`模板可复制`
- 价值词：`精选`、`实战`、`案例库`、`系统版`
