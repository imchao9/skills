# XHS Ops Skill（完整版）

将小红书虚拟产品从“想法”推进到“可持续成交”。

## 快速开始

1. 明确阶段目标：验证需求、首单、放大转化、提升客单。
2. 固定输入：关键词、人群、对标链接、当前商品、目标指标。
3. 优先执行“选品 -> 对标 -> SKU -> 详情页 -> 内容 -> 复盘”闭环。
4. 输出必须落文件：方案、表格、脚本、周报，不只给口头建议。

## 输入清单

- 关键词（3-10 个）
- 目标人群（1-2 类）
- 对标链接（>=5）
- 当前商品信息（若已有）
- 本周目标（如：首单、50 单、验证转化率）
- 当前阶段（冷启动/有单放大/高客单升级）

## 执行协议（固定顺序）

1. 用“五具体”收敛选品，不做大而全。
2. 用“异常值”拆解对标，不只看总销量。
3. 先定 L1/L2/L3 结构，再写详情页。
4. 用 `Why + What` 产出可下单文案。
5. 用自然流内容 + 评论区链接验证转化。
6. 以周为单位复盘，保留有效策略，淘汰无效策略。

## 输出协议（必须给交付件）

用户请求任何运营方案时，至少输出以下之一：

- `选品定位卡`
- `竞品拆解表`
- `SKU 梯度表`
- `详情页文案稿`
- `7天内容排期`
- `周复盘报告`

## 默认指标阈值（可调整）

- 赞藏比 >= 1.0
- 评论率 >= 3%
- 私信率 >= 1.5%
- L1 支付转化 >= 2.5%
- 退款率 < 5%

## 红线（不得忽略）

- 不用“资料数量”替代“结果承诺”。
- 不跳过评论区异议词分析。
- 不在无差异化前提下卷低价。
- 不连续复用低质笔记模板。
