# 交付控制模板

该产物用于控制执行。链接已确认的 spec 和 tracker 票据；不要在这里复制完整内容。

```markdown
# <Feature> 交付控制

## 事实来源
- 产品意图/契约：<spec 或计划链接>
- 票据结果/依赖：<tracker 或本地 issue 目录>
- 运行时账本：本文档

## 目标与边界
- 用户可见结果：...
- 范围内：...
- 范围外：...
- 已授权变更：...
- 需要单独授权：...

## Done Contract
| 层级 | 所需证据 | 是否必需 |
|---|---|---|
| 已实现 | ... | 是 |
| 自动验证 | ... | 是 |
| 已集成 | ... | 是 |
| 已部署 | ... | 否 / 是 |
| 上游读回 | ... | 否 / 是 |
| 人工/现场验收 | ... | 否 / 是 |

## 事实与未解决门禁
- 事实：...
- 假设：...
- 未知项：...
- 外部依赖：...

## 批次账本
| 批次 | 票据链接 | 状态 | 被谁阻塞 | 负责人/角色 | 模型决策 | 上下文策略 | 工作区 | 入口条件 | 批次门禁 | 证据/阻塞项 |
|---|---|---|---|---|---|---|---|---|---|---|
| 1 | ... | ready | 无 | worker | 继承父模型：边界清晰的切片 | 精简新鲜简报 | ... | ... | ... | ... |

## 集成与发布
- 共享契约负责人：...
- 集成顺序：...
- 回归门禁：...
- 独立审查：...
- 发布/读回门禁：...
- 回滚或 fail-closed 边界：...
```

## 派工简报

```markdown
票据：<链接、标题和垂直交付结果>
来源：<spec/契约与交付账本链接>
前置项：<已完成的前置项与证据>
所有权：<文件/模块/系统边界>
契约：<输入、输出、状态转换、失败行为>
验收：<命令与可观察结果>
模型/上下文理由：<该角色与上下文策略为何合适>
边界：<停止条件；未经授权不得 commit、部署或修改生产数据>
协作：你并非独自在代码库中工作。保留无关修改，不得回退其他 Agent 的工作。
返回：变更文件、已运行检查、失败项、剩余集成与外部门禁。
```
